# Extract Coefficients for glmELE

Extract Coefficients for glmELE

## Usage

``` r
# S3 method for class 'glmELE'
coef(object, weight.matrix = NULL, ...)
```

## Arguments

- object:

  A fitted glmELE object.

- weight.matrix:

  Character specifying which weighting method to return.

- ...:

  Additional arguments.
